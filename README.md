# ⛅ App de Clima com Flask e API 🌡️

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Status-Concluído](https://img.shields.io/badge/Status-Concluído-brightgreen?style=for-the-badge&logoColor=white)

Aplicação web desenvolvida em Python + Flask que consome a API da OpenWeatherMap para exibir informações climáticas em tempo real.

---
## 📚 Aprendizados
- Consumo de APIs com requests
- Uso de API Key
- Variáveis de ambiente (segurança)
- Tratamento de erros HTTP (404, 401, etc.)
- Deploy com Gunicorn

## ⚙️ Funcionalidades
O usuário informa uma cidade e o sistema retorna:

🌡️ Temperatura atual

🤗 Sensação térmica

🌥️ Descrição do clima

🖼️ Ícone ilustrativo

## 🛠️ Stack
- Python
- HTML5
- Flask
